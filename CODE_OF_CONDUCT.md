# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and considerate in project spaces. Harassment,
threats, discrimination, and other unacceptable behavior are not tolerated.

Report conduct concerns privately to the maintainers. Use the repository's
[GitHub Security Advisories](https://github.com/rookslog/mcp-machine-fabric/security/advisories/new)
when a report includes sensitive or security-related information. Maintainers
will review reports in confidence and take proportionate action. Do not use a
public issue for a private report.
